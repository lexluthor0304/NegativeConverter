# Studio の 8-bit UI と空状態の修正

空状態で未使用の `canvasTransformWrapper` が既定の 300px 幅を占有し、
アップロード欄と横並びになっていた。写真がない間だけ画布ラッパーと画像状態行を
レイアウトから外し、導入欄を全画面の中央へ配置する。写真を開いた後の画布は変更しない。

選択ボタンを共通の行へ配置し、多枚数の選択・フォルダー選択・ドラッグの案内を追加。
文字・方角の輪郭・角形のパーフォレーション・小さな硬い影を使い、空状態にだけ薄いドット背景を表示する。
新しい `studio-pixel.css` は画面の部品と動きを担当し、写真をピクセル化しない。
既存の CJK / Latin ピクセル字体、16bit 処理、原寸出力、複数写真の操作は維持する。

アニメーションはフィルムフレームの順送り、ボタン押下、メニュー表示、ロードのステップ回転と
進捗バー。`steps()` を使用し、`prefers-reduced-motion` ではアニメーションを止める。
連続点滅・画面全体の点滅・写真への装飾は追加しない。

## 旧 UI の削除

旧ヘッダー・フッターの画面構造、Mac App Store の重複バナー、段階ナビゲーション、
旧初心者ガイド、Frontier ガイドポップアップ、Quick / Detail 切替、旧 SEO 装飾欄、
夕焼け・レーザー・床グリッドの装飾と旧 hardware skin を削除。
ガイドの生成処理・タイマーに無関係な表示処理・旧表示モードの保存処理も削除した。
リセット・元画像から再処理・新規セッションは関数を直接呼び、旧フッターボタンは残さない。

初期 HTML に置いた共有部品は新しい Studio の各場所へ移し、受け渡し用コンテナーを破棄する。
GitHub・デスクトップ・フィードバック・プライバシー・ショップ、バージョン表示、言語選択、
曲線・ヒストグラム・CMYD・片基・レンズ・エンジン・除塵は新 UI の機能として残す。
画像処理用の legacy positive エンジンは「旧 UI」とは別物なので削除しない。

## 検証

`workspace-ui-smoke.mjs` で旧マークアップが非表示ではなく実際に存在しないこと、
2048 / 1440 / 390 / 320px と横長の短い画面での中央配置・ボタンの位置と大きさ、
複数選択、コマ送りアニメーション、動きを減らす設定を検証する。
スクリーンショットは `output/playwright/empty-layout-{width}.png`。

実行結果: 単体テスト 48/48、全 Chrome smoke、Web build が成功。
旧 DOM 削除後の参照エラーがないことも、全シナリオのページ例外収集で確認した。

元の写真・ユーザーの保存ファイルを削除していない。公開・コミットは行っていない。
