# Studio ワークスペース

## 起動

`npm run dev:web -- --host 127.0.0.1 --port 5198 --strictPort`

- 標準入口: `http://127.0.0.1:5198/?lang=zh`
- 以前の `?workspace=studio` のリンクも同じ画面を開く。
- `lang=ja` / `lang=en` にも対応。

Studio を唯一の画面に統一し、従来画面への分岐と切り替えリンクを削除。`?workspace=classic` も同じ画面を開く。共用コントロールと処理ロジックは維持する。リロードを越える編集セッション保存は今回の対象外。未保存の結果がある場合、リロード前に書き出す。

## 変更内容

- 写真主体の中立的なダークグレー。右側は色のスタイルと明るさ・コントラスト・色温度・色かぶり・彩度の 5 項目。
- 読み込み後に自動でフィルムベースを推定し変換。初期設定はカラーネガ、標準カラーモデル。旧画面の Frontier 自動適用分岐は削除し、案内ポップアップは表示しない。
- ブランド表示は `NeoAnalogLab`、副題は `Negative Converter`。省略記号の `n / p` は使用しない。
- 英字・簡体字・繁体字・日本語・韓国語に Fusion Pixel 12px proportional（2026.09.01、OFL 1.1）を同梱。本文は 12px、見出しは 24px / 36px。言語別フォントをローカルから読み込み、CDN に依存しない。
- 読み込み時に撮影窓と傾きを検出し、高信頼の場合のみ自動裁切する。チェックを外すと端文字・穴を保持し、撮影窓は色解析にのみ使う。不確かな検出では全体を保持する。除塵は自動適用しない。
- 既存のコントロール DOM を移動し、スライダー処理・履歴・高解像度処理・書き出し経路を再利用。
- 写真一覧を下部に配置。チェック・全選択・選択解除・Shift による範囲選択、選択数の表示、色調整の同期。
- 同期は明示的な色設定の許可リストで行う。受信先の切り抜き・回転・ミラー・フィルムベース・WB 校正ゲイン・レンズ設定をコピー元で上書きしない。
- 未表示の写真には色設定だけを保持し、読み込み時・書き出し時にその写真のフィルムベースを推定する。
- 標準画像の一覧用サムネイルは一枚ずつ縮小。RAW は実際に読み込んだときのプレビューを使用する。
- 書き出しは「現在の写真」「選択した N 枚」を優先。形式・ビット深度などは展開式。
- モバイルでは写真・写真一覧・スクロール可能な調色パネルを縦に配置。WebGL バッファのサイズ変更後に再描画し、黒いプレビューになる問題を修正。

## 検証

- 色同期の設定分離、深いコピー、サムネイルの縦横比を `npm test` で検証。
- `npm run test:smoke`: 変換・除塵・曲線・履歴・複数ファイル書き出し・破損ファイル切り替えを唯一の画面で実際の Chrome により検証。旧リンクの互換性と CJK / 英字の実際の描画フォントも確認。
- 3 枚の合成ネガ入力、自動変換、未表示写真への色同期、リセットの取り消し、再表示時の設定維持、未表示の 1 枚を含む 3 枚の実エンコード、390 × 844 のレイアウトと描画ピクセルを検証。
- `npm run test:smoke -- --studio-only` で新画面のみを実行できる。
- スクリーンショット: `output/playwright/studio-{empty,desktop,batch,export,mobile}.png`

スクリーンショット用の入力は既存の正像 JPEG に既知の反転・色マスクを加えた回帰用の合成ネガ。実フィルムの色再現精度を保証する資料ではない。実際の各種ネガ・RAW を使った仕上がり評価と、Tauri / Mac App Store 実機での新レイアウト確認は別途必要。

コミット・公開・デプロイは行わない。

## 追加修正: 切り抜きと GitHub

- 専門機能を削除しない方針を確認。曲線・ヒストグラム・CMYD・レンズ・フィルムベース・エンジン・除塵の既存入口を維持。
- GitHub リンクとスター数を元の DOM ごとシンプル版のトップバーへ移動。モバイルでも GitHub アイコンを常時表示。
- 調色直後に切り抜きを開始すると、非同期レンダリングが草稿用 2D 画布を GPU 表示に置き換え、画布寸法まで変更する不具合を再現。
- 変換結果の状態更新は継続できるが、切り抜き中は通常プレビュー・マスク描画・画布寸法変更を抑制。キャンセル時に通常画布の寸法を復元。
- 切り抜き適用後に古いプレビュー変換結果が入り込まないよう、非同期処理で入力画像の同一性も確認。
- 切り抜き中のズームと競合する操作を抑制。専門機能の処理自体は維持。
- 回帰テストに非同期更新との競合、実マウスドラッグ、適用・キャンセル・取り消し・やり直し、およびモバイルの実タッチ操作を追加。

## 標準画面への移行と機能対応

機能を減らさず、既存 DOM と処理を用途別のタブへ移動する。旧ステップの表示制約が残る自動取景は、内部で既存経路を実行した後、自動的に調色状態へ戻す。

| 入口 | 機能 |
| --- | --- |
| 色調整 | 常設ヒストグラム、5 基本スライダー、灰点、CMYD、独立カーブ、全モデル・プリセット、階調・色・RGB/CMY の詳細調整 |
| 構図 | 手動切り抜き、回転、ミラー、現在／選択写真の自動取景、取景設定 |
| 修復 | 除塵の有効化・感度・粒子サイズ・マスク・ブラシ、レンズ検索／選択／各補正パラメーター、再変換 |
| 枠 | パーフォレーション表示、文字・フレーム番号・DX・半コマ・光漏れ・フォント・色・配置、枠付き書き出し |
| 変換 | ネガ／白黒／ポジ、フィルムベース、同一ロール参照、エンジン、再変換、調整リセット、元画像から再処理 |
| 下部写真一覧 | 複数選択・範囲選択・全選択／解除、色同期、一括処理設定の同期、一覧消去 |
| 上部 | 追加、取り消し／やり直し、統一書き出し、GitHub、言語・ヘルプ・新規セッション |

デスクトップ版・フィードバック・プライバシー・グッズの入口は上部に常設する。

裁切後の色変化への対応は [裁切と色解析範囲の分離](crop-color-analysis-2026-09-06.md) を参照。

- 処理設定の同期では、色だけでなくフィルムベース・WB 補正ゲイン・レンズ等もコピーするため確認を表示する。既存実装どおり、各写真の切り抜き・回転・ミラーは保持する。構図もコピーしたい場合はロール参照の「切り抜きも適用」を使う。
- 枠設定を変更するとプレビューを自動で有効にする。書き出しは統一メニューの明示的なチェックで選択し、通常の書き出しボタンを押しても指定を解除しない。
- 枠は追加描画であり、元画像で失われた情報の復元ではない。枠・文字の設定は書き出し対象の全写真で共有する（自動連番の追加は行わない）。
- パネルはキーボードでも切り替え可能。カーブは初めて寸法を得た時（引き出し・タブ・ジャンプボタン）に ResizeObserver が描画する。右パネル／写真一覧の折り畳みでは表示枠だけを合わせ直し、WebGL は描き直さない（表示用プレビューは 100ms 後に新しい寸法で届く）。
- デスクトップの上部バーと写真一覧を低くし、右パネルの重複する説明を整理。写真を広げたいときは「調整を隠す」「写真一覧を隠す」を使える。
- 一覧消去、新規セッション、原片からのやり直しには確認を置く。元ファイルは削除しない。

追加のブラウザー検証では、タブの DOM 存在だけでなく、実マウス操作で枠を有効化し、画布の拡張・白い齿孔ピクセル・色付き端文字ピクセルを検査する。枠付き PNG の生成、統一書き出しの枠指定維持、全タブの主要入口、パネル折り畳み、自動取景からの復帰も対象とする。

## 画面同期とレイアウト（#261）

- **一回の同期にまとめる。** `studioWorkspace.sync()` は「古い」印を付けてマイクロタスクを一つ予約するだけで、同じ同期実行中の呼び出し（スライダー・カーブの確定で 2 回、ステップ変更で 3 回、キャッシュ済み写真への切り替えで約 10 回）は一回の flush になる。マイクロタスクは次のタスクより先に実行されるため、`inert`・`disabled` は待機中のクリックより先に効く（rAF ではこれが保証されない）。`sync()` の後に `await` する処理も、busy 状態を描いてから待つ。同じターンで書き込みを読む呼び出し元は `flush()` を使う。現在は未キャッシュ写真への切り替えの告知だけ（クリックした側が同じスクリプト内で表示を読む）。
- **差分書き込み。** flush の書き込みはすべて `set(el, key, value)` を通り、実際の DOM の値（文字列・`disabled`・`hidden`・`inert`・`checked`・`style.display`・属性・クラス）と比べて違う時だけ書く。何も変わっていない flush は DOM に書かない。未キャッシュ写真への切り替え中のベールの表示（`createPhotoSwitchPresentation`）では、flush が呼ぶ「プレビュー」チップの書き換えとベールを閉じる時の解放も同じ `set` を通り、書き込みとして数えられる。要素の参照はマウント時に一度だけ解決し、`[data-studio]` の一覧は言語が変わった時だけ集め直す。写真一覧の行は、切り替え先・現在の写真・一覧の再描画（`markRowsChanged`）・言語のどれかが変わった時だけ照合する。
- **書き手は一つ。** `saveSettingsBtn`/`applyToSelectedBtn` の `display`、`exportBtn`・`exportSprocketBtn`・`exportSingleBtn` の文言、`exportBtn`・`exportSprocketBtn` の `disabled` は同期だけが書く。三つの書き出しボタンはマウント時に `data-i18n` を外し、`setLanguage` が書かないようにする。`exportSingleBtn.disabled` は従来どおり `updateExportButtons` が書く。
- **合成 `resize` をやめる。** 引き出し・タブ・色のジャンプボタン・パネル／写真一覧／ライトテーブルの切り替え・準備完了の変化で `window` に `resize` を送らない。一つの ResizeObserver が `#canvasContainer`（#233 と共用）、`#histogramContainer`、`#curveCanvas` を見て、先に全部の寸法を読み、後で書く。表示枠は実際に寸法が変わった時だけ一度合わせ直し、描画バッファがテクスチャと一致しない時だけ WebGL を描く。ヒストグラムの幅はボーダーボックスから左右の余白（一度だけ読む）を引いた値で、描画時にレイアウトを読まない。カーブは CSS 寸法をキャッシュし、寸法が変わった時だけ画布を確保し直す（描かれる曲線は同じ）。ドラッグ中はマウスダウン時の位置を使い、リサイズやスクロールで捨てる。ResizeObserver のない環境だけ `window` の `resize` を使う。DPR の変化は #233 の `matchMedia` が扱う。
- **隠れた読み込み表示は止める。** `studio.css` で、`.visible` のない `.loading-overlay` はフェードの終わりに `visibility: hidden` になり（遅延はフェードの長さと同じ値）、リールと帯の無限アニメーションは `paused` になる。WebKit は `steps()` のアニメーションを見えなくても毎段階で主スレッドを起こすため。規則は `animation` の一括指定（`animation-play-state` を戻す）より後に置く。フェード中の段階表示と長さ（300ms）は変えない。進捗の文言は画面外の `role="status"` 要素（`.loading-status`）が読み上げる。

検証: `studioWorkspace.test.mjs` がまとめ（一回の同期実行で一回、次のタスクより前、`flush()` で即時、`await` の前後で二回）と差分書き込み（同じ値なら書かない、実際の DOM で判断、ベールの表示中に変化のない flush はチップも書かず 0 回と数える）、合成 `resize` がないこと、書き手が一つであることを確認する。Chrome smoke の `studio-sync-smoke.mjs`（`--studio-sync-only`、`?debugCounters=1`）は、確定・取り消し・写真切り替えが一回の flush であること、変化のない flush が 0 回書くこと、三言語 × 四形式のボタン文言、寸法の変わらないレイアウト変更で合わせ直し・再描画がないこと、カーブの初回表示とドラッグ中の再確保なし、読み込み表示のフェードと停止を確認する。`smoke-test.mjs`（再変換の後）・`crop-apply-smoke.mjs`（不確定表示の帯を出す裁切の適用の後）・`photo-session-smoke.mjs`（未キャッシュ写真への切り替えの後。切り替え自体は読み込み表示を出さない）・`studio-raw-autoframe-smoke.mjs` も、読み込み表示を隠した後にアニメーションが動いていないことを確認する。この確認は、呼び出し側が「読み込み表示はない」と指定しない限り、読み込み表示が一度も作られていないページでは失敗する。VoiceOver の読み上げと WKWebView のタイムラインは手動確認が必要。
