## 残る改善候補

1. 除塵の検出は引き続きメインスレッドで画像全体を処理する。修復とスマートブラシには下記の領域限定処理を追加した。大きなRAWでのさらなる応答性改善にはWorker移行や離れたマスクの分割処理が必要。
2. 修復領域のRGBはOpenCVの8ビット出力に基づく。マスク外は元の16ビット精度を保持するが、修復アルゴリズム自体の16ビット化は未対応。
3. `main.js` は約1.17万行あり、検出・ファイル切替・書き出し・履歴の状態管理が集中している。今回の動作テストを維持しながら機能単位に分割すると変更を検証しやすくなる。
4. 120フィルム等で穴列の証拠がない密度候補の信頼度上限は0.68のまま。誤裁切を増やさず自動適用を広げるには、複数フォーマットの正解付き画像による精度評価が必要。
5. スモークのバッチ出力検証は個別PNGの経路。実RAW入力、16ビットTIFF、ストリーミングZIPのブラウザ一貫テストを追加する余地がある。
6. 通常のmacOSリリースジョブはホストアーキテクチャでビルドしている。Intel向け配布についてはuniversalビルドと配布ページの選択動作を合わせて検証する必要がある。

## 追加改善：除塵の局所処理

全マスクの外接矩形に修復半径＋2画素の余白を加え、その範囲だけOpenCVへ渡すよう変更した。範囲が全画面の75%以上を占める場合は全画面経路を使い、無駄な切り出しを避ける。スマートブラシでは筆跡の外接矩形を直接求め、全画面のグレースケール化と範囲取得用の輪郭抽出を省いた。空マスクはOpenCV処理を省き、8/16ビットの画像を複製する。

局所処理後も出力サイズは元画像と同じ。未修復の元画像から出力を構成するため、マスクの削除時には過去の修復画素も元に戻る。マスク外の16ビット精度と全画素のアルファを保持する。

`node scripts/bench-dust.mjs [比較対象モジュールのパス]` で同一の3000×2000合成画像を測定した。1回のウォームアップ後、5回の中央値。変更前はこの追加改善の開始時点のコードを使用した。

| 処理 | 変更前 | 変更後 | 比率 |
| --- | ---: | ---: | ---: |
| 中央5×5画素のマスク修復 | 108.34 ms | 10.36 ms | 約10.5倍 |
| 空マスクの修復 | 111.81 ms | 6.84 ms | 約16.3倍 |
| 直径41画素のスマートブラシ | 11.85 ms | 5.37 ms | 約2.2倍 |

3処理とも変更前後の出力SHA-256が一致した。この測定は8ビット合成画像のエンジン処理時間であり、描画・ファイル読込・全体の粒子検出を含まない。実画像の操作全体が同じ倍率で速くなるという意味ではない。

追加の `DustRemoval.regional.test.mjs` では、画像端・隅・細線・分散粒子・密なマスクを含む30種×3半径の90ケースを全画面OpenCV処理と逐画素比較した。追加・部分削除・全削除も検証し、スマートブラシは変更前に記録した6ケースのマスクハッシュとの一致を確認した。局所処理でOpenCVへ渡す寸法と、空マスクでOpenCVを呼ばないことも確認した。

追加改善後の `npm test` は34/34成功、`npm run build:web` も成功。`npm run test:smoke` は実Chromeで除塵・マスクのクリア・直接ブラシ・曲線編集・2ファイルのPNG出力まで成功した。変更前後の出力ファイルサイズも同じだった。

| --- | --- | --- |

PNGについては、調査の続きで `loadStandardImage` に既存の内容識別による16ビット保護があることを確認した。従って「空MIMEなら精度が失われる」とした先の評価は過大であり、今回の対応は分岐の統一と実データによる回帰検証である。

この段階の単体・整合性検証はJavaScript 38/38、Rust 22/22が成功。ブラウザ回帰では既存の変換・除塵・曲線編集・PNG出力に加え、Worker結果一致、セレクトの撤回、破損ファイル切替を確認した。

制限：Worker/OffscreenCanvasがない環境やWorker障害時には従来の主スレッド処理を使う。検出アルゴリズム自体の処理量や裁切精度を変更したものではない。デスクトップの輸送用追加メモリはチャンク単位になるが、エンコード済みBlob自体のメモリは残る。MASで隣接一時ファイルを作れない場合は一時ディレクトリからストリームコピーするため、最終コピーは原子的ではない。署名済みMASアプリの保存パネルを含む実機試験は未実施で、実リリースやストア提出も行っていない。
