RAW decoder notices
==============================================================================

Negative Converter decodes RAW files with LibRaw 0.22.1, unmodified. The web
app and the desktop apps run it compiled to WebAssembly (the libraw-wasm
package). The macOS and Linux desktop apps also contain it compiled
natively and statically linked into the application: there its
mathematical functions pow, powf, exp, log, logf and cos come from musl
1.2.6, and on macOS its parallel regions run on the LLVM OpenMP runtime
(libomp 22.1.8), statically linked as well.

COMMON DEVELOPMENT AND DISTRIBUTION LICENSE (CDDL) Version 1.0, reproduced
below. The source code of LibRaw is available from
https://github.com/LibRaw/LibRaw (tag 0.22.1, commit
b860248a89d9082b8e0a1e202e516f46af9adb29) and, exactly as compiled into this
app, in the app's source repository under src-tauri/vendor/libraw
(https://github.com/lexluthor0304/NegativeConverter).
